# Mario Charts

## Register

product

## Users

Mario Charts serves React and TypeScript developers building production dashboards, internal tools, and data-rich applications. They want polished charts quickly, but need to understand, own, and adapt the implementation instead of depending on a black-box component library.

## Product Purpose

Mario Charts provides production-ready chart components with strong defaults, accessible interactions, and copy-paste ownership. The product succeeds when a developer can discover the right component, install it in minutes, understand its API from a working example, and confidently adapt the source to their product.

## Brand Personality

Precise, refined, and technical. The experience should feel mature and carefully engineered while remaining direct and approachable. It should earn trust through clarity, consistency, and the quality of its working components rather than decorative effects.

## Anti-references

- Generic SaaS landing pages built from repeated rounded cards.
- Purple-blue gradients, gradient text, glassmorphism, glow effects, and decorative blur.
- Dark developer-tool styling used as a shortcut for sophistication.
- Excessive shadows, oversized headings, and long entrance animations.
- Explicit game imagery, pixel art, characters, or novelty styling in primary workflows.
- Interfaces that imitate Vercel, Geist, or Resend without a product-specific reason.

## Design Principles

### Demonstrate the product

Charts, real data, code, and interaction should carry the story. Prefer working examples over claims about flexibility or beauty.

### Make developer experience visible

Installation, customization, API discovery, and source ownership are first-class interface workflows. Code and rendered output should behave as one connected surface.

### Earn a premium feel through precision

Use typography, grid, density, alignment, interaction states, and restrained materials to create quality. Do not rely on decoration to imply quality.

### Let chart craft become the signature

The recognizable Mario Charts character comes from consistent axes, legends, tooltips, data states, motion, and chart composition. Brand recognition does not depend on one accent color.

### Keep the ecosystem coherent

The home page, documentation, component pages, and dashboard examples share one component vocabulary and visual system while adapting their density to the task.

## Accessibility & Inclusion

- Meet WCAG 2.1 AA for text, controls, focus indicators, and meaningful graphics.
- Support complete keyboard operation with visible `:focus-visible` states.
- Preserve functionality under `prefers-reduced-motion`.
- Use redundant cues and color-blind-safe defaults for data series and semantic states.
- Support browser zoom to 200% without loss of content or essential functionality.
